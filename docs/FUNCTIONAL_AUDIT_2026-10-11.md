# 现有功能检查与修复（2026-10-11）

检查基线：远端 main `7ccaa3154cad286812ca7913e0223e1d7fb1af06`。本轮聚焦现有功能，不重建架构，不新增付费或 AI 依赖。

## 本轮修复

1. **更多设置打开即消失**：真实浏览器复现。设置 Dialog 挂在 Popover.Panel 下，焦点进入 portal 会关闭菜单并卸载 Dialog。保持菜单内容挂载，让设置和指法图示弹窗独立完成关闭流程；未改变学习事实。
2. **备份失败卡死 / 错误不显示**：导入异步处理从无人等待的 DOM change listener 改为可等待的文件导入函数。界面捕获失败、释放忙碌状态、允许重新选择同一文件，并互斥导入/导出。数据库进度结束不再过早显示整个操作成功；恢复后提供刷新入口。保留 staging 校验及事务导入。
3. **尾章词少无法选择词义**：题目仍只考用户选中的目标词；干扰项允许取同词书的有界参考范围，最多检查 120 词并在尾章回绕，保留精确词条版本。不会把借来的选项计成已学目标，也不会伪造释义。
4. **词义页面 SPA 换段残留答案**：回想与选择词义按 run 和账号访问代次重建页面状态；不存在的新 run 不再保留旧词、释义或反馈。账号切换（包括 A→B→A）使旧访问失效；旧回调不得导航到新访问。真实已保存事实仍留在原 run。
5. **词义统计读取过多历史**：复用已有 owner 索引查询，读取当前账号事实后再派生统计；匿名历史仍有独立过滤，指标口径不变。
6. **发音参数编码**：所有语言的发音词条先做 URL 编码，避免词组中的 `&`、`#`、`+` 被当作查询参数或片段；罗马音转换后再编码。
