# Wenyan · Luminous Paper / 纸上微光

更新：2026-10-12。

这不是“纸张背景 + 星空特效”的主题，也不是一套换色后的 SaaS 皮肤。它是 Wenyan 长期使用的视觉与交互语言。

## 1. 核心模型

- **Paper = knowledge, memory, truth**：稳定、可回看、可引用的学习内容与历史。
- **Ink = what has settled**：已经发生、已经确认、已经写入记录的内容。
- **Light = attention, cognition, change**：正在专注、正在输入、刚刚理解、刚刚建立联系、刚刚完成的瞬态变化。

一句设计宪法：

> **光不占据页面，光只占据时间。**

任何光效都必须在短时间内退场，最终重新沉成安静的墨迹。

## 2. 材质秩序

Wenyan 不模拟纸纹，不使用书房、古风、水墨、星空、银河等具象装饰。

界面材料分为：

1. **Ground**：环境层，微暖、低对比、几乎不可察觉。
2. **Paper**：主要工作面，连续而稳定，不依赖卡片墙分组。
3. **Ink**：内容与事实，靠排版、留白、规则线、字重建立层级。
4. **Tool**：临时工具可以轻微浮起；知识本身尽量不浮。
5. **Lumen**：只在认知变化发生时出现的瞬态局部亮度。

## 3. 空间原型

未来英语与文学内容统一归入三种空间，而不是为每个学科重做页面语言。

### Folio

长阅读、文学原文、真题材料、解析、知识条目。

- 中央正文控制阅读宽度。
- 允许页边注、来源、术语、关联、AI 建议进入 Marginalia。
- 知识关联优先表现为引用、回链、交叉索引，不做星空知识图谱。

### Work Surface

单词、翻译、写作、答题、专项训练。

- 主要内容位于连续工作面，不堆叠卡片。
- 输入状态通过注意力与局部光感表达，不依赖厚重输入框。
- 正确、错误、完成都属于短暂事件，随后沉回稳定状态。

### Index

词库、题库、历史、知识目录、作品与人物列表。

- 允许更高的信息密度。
- 使用列、缩进、编号、细线、时间与状态建立秩序。
- 数据是索引，不做 Dashboard 式统计卡片墙。

## 4. Lumen Grammar / 微光语法

### Focus

当前工作区域的纸面亮度极轻地提高，外围后退。禁止持续闪烁。

### Correct

字符或答案局部由内向外亮起一次，然后消失，留下普通正确状态。

### Wrong

使用低饱和暖色和短促位移提示，不喷射、不抖动过度。

### Connection

关联第一次被发现时，可用一条细光或局部边缘传递 400–800ms，之后留下普通引用或关系线。

### Completion

整张当前工作面的亮度缓慢呼吸一次，然后归静。禁止烟花、彩纸、星点、银河。

### New AI suggestion

建议第一次到达时只允许一次很弱的亮度脉冲。读过或接受后沉为普通内容。

约束：

> **同一视野原则上只有一个主要光源。**

## 5. 运动规律

- **Paper motion**：理性、短促、准确，约 140–240ms；页面与工具像被放回正确位置。
- **Light motion**：允许更柔和的扩散、衰减与传递，约 220–800ms；不循环吸引注意力。
- `prefers-reduced-motion` 必须有稳定退化。

## 6. 排版与层级

- UI、导航、状态使用现代无衬线。
- 长阅读和文学内容可使用更适合正文阅读的衬线字体，但不是全站“文学风”。
- 标题像出版物标题，不做超大 Landing Page 标语。
- 页面分组优先依靠留白、细线、字重、缩进和背景明度差，而不是圆角卡片。

## 7. 首页原则

Today 不是学习后台，而是“今天正在研究的那一页”。

优先级：

1. 上一次停在哪里；
2. 当前最值得继续什么；
3. 今天正在推进什么；
4. 新学习意图或建议；
5. 历史和统计退到边缘。

打开 Wenyan 的感觉应该是“回到了昨天离开的地方”，而不是“查看我的学习仪表盘”。

## 8. 禁止项

- 具象纸纹、纸张拟物边缘、复古书房；
- 水墨、古风纹样、星星、星空、星球、银河；
- 永久发光的品牌按钮或 AI 卡片；
- 大面积玻璃拟态、渐变背景、卡片墙；
- Linear / Notion / 普通黑白 Dashboard 的直接仿制；
- 把所有交互都做成 hover 发光。

## 9. 第一阶段母版场景

当前实现先验证三个母版：

- **Today**：验证 Paper 的安静和连续性；
- **Typing**：验证 Focus、Correct、Wrong、Completion 的瞬态光；
- **Reading**：验证 Folio、阅读定位和答题反馈。

这三个场景如果不靠相同装饰，却能一眼属于同一个 Wenyan，设计身份才算成立。

## 10. 长期判断标准

不是第一眼是否炫，而是：

- 每天打开仍然舒服；
- 真正学习时偶尔有惊喜；
- 光的出现永远有认知含义；
- 用几年以后仍不过时；
- 加入古代文学、现当代文学、外国文学、文学理论后仍成立。
