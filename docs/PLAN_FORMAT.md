# 学习计划 JSON v1

当前是本机导入与执行格式。MCP/云端自动下发尚未接通。在网站“今日学习 → 导入计划”粘贴完整 JSON。不要包含 Markdown 代码框。

```json
{
  "schemaVersion": 1,
  "id": "english-week-20261007",
  "title": "英语起步计划",
  "timezone": "Asia/Shanghai",
  "tasks": [
    {
      "id": "day-one",
      "title": "完成第一章拼写练习",
      "kind": "chapter",
      "dictId": "cet4",
      "chapterIndex": 0,
      "dueDate": "2026-10-07",
      "estimatedMinutes": 10,
      "reason": "先观察这一章的真实拼写表现，再决定后续学习量。"
    }
  ]
}
```

- 日期按计划时区展示；chapterIndex 从 0 开始，网页显示为第 1 章。
- dictId 必须存在于 `src/resources/dictionary.ts` 且为英语词书。
- 每份计划 1–60 个任务，预计每项 1–120 分钟；这些是安排估计，并非自动测得。
- 计划 ID 在本机唯一；任务 ID 在同一计划内唯一，只支持字母/数字/下划线/短横线。
- 同 ID 导入被拒绝，已有完成状态不会被覆盖。需要新安排时生成新 ID。
- 导入不会信任 completed/status 等额外字段，不允许外部 JSON 伪造完成记录。
- 点击任务会设置对应词书、章节并退出错词复习模式；“重新开始”从本章首词开始。
- 真正练完指定章节后，由章节事实记录完成；启动、切换章节或跳过单词不能代替完成。
- “导出安排”只导出计划内容，不包含学习历史、登录信息和运行进度；不能当作完整数据备份。

给 ChatGPT 的过渡提示：

> 请按 Wenyan English 的 PLAN_FORMAT.md v1 输出可导入 JSON。先问我目标词书ID、起始章节和每天可用时间，不要猜测我的历史掌握程度。没有学习数据时明确说明依据不足。只安排有效章节，不要返回完成状态。计划生成后，我会手动导入网站；这不等于插件已连接。
